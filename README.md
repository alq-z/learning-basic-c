---Common GCC Flags

-o          output executable name
-lm         math library
-pthread    threading support
-Wall       show warnings
-Wextra     extra warnings
-g          debug  info
-O2         optimization
-std=c11    use C11 standard

---Common compile command:
gcc main.c -o main -Wall -Wextra -std=c11 -lm
